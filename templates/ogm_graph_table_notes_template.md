# OGM Graph and Table Notes Template

Use this template inside the 2LOD OGM assessment file or as a companion Markdown note. It is intended for graphs, charts, tables, screenshots, and monitoring exhibits that should inform PR Section 2.1.6 or another relevant PR section.

The assistant should treat these notes as the primary interpreted evidence for graph/table discussion. The reviewer remains responsible for the assessment and final conclusion.

## Graph/Table Note Block

```text
Graph/Table ID:
Title:
Source file or workbook:
Source tab or page:
PR report section:
Monitoring test:
Current-cycle period:
Metric or population:
Threshold or benchmark:
Current-cycle result:
Prior-cycle comparison:
Trend or movement:
Breach, exception, override, or output adjustment:
Management explanation:
2LOD assessment:
Reviewer notes:
Recommended PR language:
Include in PR report? Yes / No
If included, refresh existing prior-report graph/table? Yes / No / Not applicable
If not included, rationale:
```

## Guidance

- Paste the graph/table above or below the note block when working in the 2LOD OGM assessment file.
- Use the note block to capture what the exhibit means, not just what it looks like.
- Identify the relevant PR section when the exhibit supports a section outside 2.1.6.
- State thresholds, breaches, and exceptions explicitly.
- If the graph/table should replace a prior-report exhibit, identify the prior exhibit title or page if known.
- If the exhibit should only support narrative discussion and should not be included in the PR report, mark "Include in PR report? No" and explain why.
